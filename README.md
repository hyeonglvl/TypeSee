# TypeSee

Type and Learn — 타이핑하며 눈에 새기는 영단어 앱.

## 핵심 기능

### TS-1 — 오답 단어 출현 확률 알고리즘

처음에는 SM-2(SuperMemo-2)와 FSRS 도입을 고려했으나, 유저가 매일 접속하지 못하는 경우와
틀린 단어를 최소 하루 간격으로 다시 보여줄 수 없는 서비스 특성을 고려해
직접 고안한 **TS-1** 알고리즘 구현.

**동작 방식**

- 단어마다 ease factor를 두고, 틀리면 값이 내려가고 맞히면 올라감.
- 세션 단어를 뽑을 때 ease factor가 낮을수록 출현 확률(가중치)이 높아져,
  자주 틀리는 단어가 잘 맞출 때까지 더 자주 등장.
- **시간 가중치**: 오래 안 본 단어일수록 출현 확률이 최대 3×까지 올라(7일 포화),
  날짜 스케줄 없이 간격 효과(spacing effect)를 근사.
- 정타로 통과할수록 출현 확률이 점점 낮아지고, 마스터하면 복습 풀에서 졸업.
- **마스터 유지 점검**: 마스터한 단어도 3일 뒤부터 일반 세션에 배지 없이 가끔
  재출현(세션당 1~2개). 통과하면 마스터 유지, 틀리면 복습 풀로 복귀.
- 정타로 통과한 단어는 바로 다음 세션에서 한 번 쉬어(쿨다운), 방금 맞힌 단어가 곧바로 다시 나오지 않게 조절.

**SM-2 vs FSRS vs TS-1**

| | 장점 | 단점 |
|---|---|---|
| **SM-2** | 검증된 간격 반복(spaced repetition). 기억이 흐려지는 시점에 맞춰 복습시켜 장기 기억 효율이 높음. | 날짜 기반 스케줄이라 매일 접속을 전제로 함. 며칠 놓치면 밀린 복습이 쌓이고, 시기를 놓친 단어는 학습 효과가 급감. |
| **FSRS** | 기억 모델(난이도·안정성·회상 확률) 기반으로 유저별 최적 간격을 학습. SM-2보다 적은 복습으로 같은 기억률 달성. | 여전히 날짜 기반이라 매일 접속 전제는 동일. 파라미터 학습에 충분한 복습 기록 데이터가 필요하고 구현이 복잡. |
| **TS-1** | 접속 빈도와 무관. 언제 들어와도 밀린 복습 없이 약한 단어부터 확률적으로 등장하므로 스케줄 관리가 필요 없음. | 시간 기반 간격 효과(spacing effect)가 약해 같은 단어가 짧은 간격으로 반복될 수 있음. 쿨다운으로 보완. |

### 학습

- **Typing / Quiz / Listening 모드**: 단어를 보고 치거나, 뜻만 보고 철자를 떠올리거나, 발음만 듣고 받아쓰기 (퀴즈·리스닝 오답 즉시 표시, Space로 정답 보기, Tab으로 다시 듣기)
- **예문 학습**: 단어별 예문과 한글 해석 표시, 스페이스로 저장/스킵. 리스닝은 예문 문장 속 빈 슬롯에 받아쓰기 (해석은 답을 흘리므로 숨김)
- **틀린 단어 복습**: 세션에서 틀린 단어가 자동으로 모이고, 노트에서 틀린 횟수 확인·재도전. TS-1 임계값에 도달하면 마스터 처리. 세션 카드 배지에 익힘 단계(점 5개) 표시
  - 로그인 전용: `missed_words` 테이블에 저장되어 어디서든 복원 (ease factor 포함). 게스트는 Note 비활성화
- **내 단어장**: Gemini 3.1 Flash-lite로 원하는 단어의 뜻·예문을 생성해 나만의 단어장 구성 (최대 100개, 로그인 전용)

### 기록·편의

- **학습 스트릭 캘린더**: 홈 화면에서 날짜별 학습 기록 확인
- **라이브 스탯**: WPM·오답률 실시간 표시
- **단어 발음**: Web Speech 기반 TTS (토글)
- **키보드 온리 조작** + 모바일 반응형 (타이핑 키보드 지원)
- **한/영 자동 처리**: 한글 IME가 켜져 있어도 물리 키 위치로 영어를 강제 입력

## 스택

- **Next.js 16** (App Router) + **React 19** + **TypeScript**
- **React Compiler** (babel-plugin-react-compiler)
- **Motion** — 애니메이션
- **Supabase** — 인증 (아이디/비밀번호 · Google 로그인), 틀린 단어·학습 기록 저장 ([`supabase/schema.sql`](supabase/schema.sql))
- **CSS Modules** — 화면별 스타일
- **Vitest** — 세션 엔진·TS-1 알고리즘 테스트 (`npm test`)

## 구조

```
src/
  app/                    # Next.js 엔트리 (layout, page)
  App.tsx                 # 화면 전환 (홈 → 세션 → 결과 → 복습)
  lib/
    engine.ts             # 세션 리듀서·통계 (순수 함수)
    types.ts              # 공용 타입 (WordEntry, SessionState 등)
    reviewStore.ts        # 틀린 단어 풀 (메모리 + DB 동기화)
    streakStore.ts        # 학습 스트릭 기록
    auth.ts               # Supabase 인증
    supabase.ts           # Supabase 클라이언트
    tts.ts                # 단어 발음
  screens/                # Home · Session · Result · Review · MyWords
                          # HistorySheet · AuthSheet · StreakCalendar
  data/                   # 단어 데이터 (wordjson.json + 카테고리)
  styles/global.css       # 전역 스타일
```

브랜치: `hyeong-dev-v1` = 구버전(v1) 백업.
