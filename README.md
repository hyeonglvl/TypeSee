# TypeSee

Type and Learn — 타이핑하며 눈에 새기는 영단어 앱.

## 앱 소개

- **Typing / Quiz / Listening** 세 모드로 단어를 익힌다: 보고 치기, 뜻만 보고 철자 떠올리기, 발음만 듣고 받아쓰기.
- 단어마다 예문과 한글 해석을 함께 보여줘 문맥으로 학습하고, 틀린 단어는 자동으로 복습 노트에 쌓인다.
- **내 단어장**: 원하는 단어를 추가하면 Gemini가 뜻·예문을 생성해줘 나만의 단어장을 만들 수 있다 (로그인 전용).
- 홈 화면의 학습 스트릭 캘린더로 날짜별 기록을 확인하고, 세션 중에는 WPM·오답률이 실시간으로 표시된다.
- 단어 발음(TTS), 키보드 온리 조작 + 모바일 반응형, 한글 IME가 켜져 있어도 영어를 강제 입력하는 등 자잘한 편의도 갖췄다.

## 핵심 기능

### TS-1 — 오답 단어 출현 확률 알고리즘

처음엔 SM-2(SuperMemo-2)와 FSRS 도입을 검토했지만, 둘 다 매일 접속을 전제로 한 날짜 기반
스케줄이라 가끔 들어오는 유저에겐 맞지 않았다. 그래서 직접 고안한 **TS-1**을 쓴다.

**한 줄 요약**: 단어마다 ease factor를 매기고, 값이 낮을수록(=자주 틀릴수록) 세션에 더 자주 등장시킨다.

- 맞히면 ease factor가 오르며 출현 확률이 낮아지고, 틀리면 반대로 움직인다.
- 오래 안 본 단어는 시간 가중치가 붙어 출현 확률이 최대 3배까지 올라(7일 포화), 날짜 스케줄 없이도 간격 효과(spacing effect)를 흉내 낸다.
- 임계값을 넘기면 마스터로 졸업하되, 3일 뒤부터는 가끔 재등장시켜 유지 여부를 점검한다 — 틀리면 복습 풀로 복귀.
- 방금 맞힌 단어는 바로 다음 세션에서 한 번 쉬는 쿨다운을 둬, 맞히자마자 곧바로 다시 나오지 않게 한다.

**SM-2 vs FSRS vs TS-1**

| | 장점 | 단점 |
|---|---|---|
| **SM-2** | 검증된 간격 반복(spaced repetition)으로 장기 기억 효율이 높음. | 날짜 기반 스케줄이라 매일 접속을 전제로 함. 며칠 놓치면 밀린 복습이 쌓임. |
| **FSRS** | 기억 모델(난이도·안정성·회상 확률) 기반으로 유저별 최적 간격을 학습, SM-2보다 적은 복습으로 같은 효율. | 여전히 날짜 기반이라 매일 접속 전제는 동일. 파라미터 학습에 데이터가 필요하고 구현이 복잡. |
| **TS-1** | 접속 빈도와 무관. 언제 들어와도 밀린 복습 없이 약한 단어부터 확률적으로 등장. | 시간 기반 간격 효과가 SM-2/FSRS보다 약해 같은 단어가 짧은 간격으로 반복될 수 있음 (쿨다운으로 보완). |

## 스택

- **Next.js 16** (App Router) + **React 19** + **TypeScript**
- **React Compiler** (babel-plugin-react-compiler)
- **Motion** — 애니메이션
- **Supabase** — 인증 (아이디/비밀번호 · Google 로그인), 틀린 단어·학습 기록 저장 ([`supabase/schema.sql`](supabase/schema.sql))
- **Gemini API** (`gemini-3.1-flash-lite`) — 내 단어장 뜻·예문 생성 (`app/api/generate-word`)
- **CSS Modules** — 화면별 스타일
- **Vitest** — 세션 엔진·TS-1 알고리즘 테스트 (`npm test`)
- **Vercel Analytics**

## 구조

```
src/
  app/
    api/generate-word/     # Gemini 기반 내 단어장 생성 API
    layout.tsx, page.tsx   # Next.js 엔트리
  App.tsx                  # 화면 전환 (홈 → 세션 → 결과 → 복습)
  lib/
    engine.ts              # 세션 리듀서·통계 (순수 함수)
    types.ts               # 공용 타입 (WordEntry, SessionState 등)
    reviewStore.ts         # 틀린 단어 풀 (메모리 + DB 동기화, TS-1 ease factor)
    streakStore.ts         # 학습 스트릭 기록
    customWordsStore.ts    # 내 단어장 (Gemini 생성 결과 저장)
    auth.ts                # Supabase 인증
    supabase.ts / supabaseAdmin.ts  # Supabase 클라이언트 (브라우저 / 서버)
    tts.ts                 # 단어 발음
    homePrefs.ts / difficultyPref.ts / autoAdvancePref.ts  # 홈·세션 설정 저장
    inAppBrowser.ts         # 인앱 브라우저(카카오톡 등) 감지
  screens/                 # Home · Session · Result · Review · MyWords
                           # HistorySheet · AuthSheet · StreakCalendar
  data/                    # 단어 데이터 (wordjson.json + words.ts / index.ts)
  styles/global.css        # 전역 스타일
```

브랜치: `hyeong-dev-v1` = 구버전(v1) 백업.
